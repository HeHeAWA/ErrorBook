# 个人错题集管理系统

> 一个**后端零第三方依赖、零数据库**的错题管理 Web 应用：前端为 **Vue 3 + Vite 单页应用（SPA）**，后端为**原生 Node.js**（仅用 Node 内置模块，无 Express / Koa）。用户可收录自己的错题、浏览公共错题广场、用 OCR 快速识别整卷中的错题，并通过可视化分析报告查漏补缺。

---

## 一、项目简介

本系统帮助用户沉淀学习中的错题：记录题目、答案、解析与图片，按年级 / 学科 / 错误类型归类；支持将错题公开到「错题广场」与他人共享、互相点赞收藏；提供「错题分析」可视化报告与「错题排行榜」；并内置「识别错题」功能，用浏览器端 OCR 一键识别整卷批改结果，自动挑出易错题目。

- **前端 Vue 3 SPA + 原生 Node.js 后端**：前端基于 Vue 3（Composition API + `<script setup>`）、vue-router 4 与 Vite 构建；后端无 Express / Koa，所有运行时依赖均为 Node 内置模块（前端仅在构建期依赖 vue / vite / @vitejs/plugin-vue）。
- **本地 JSON 存储**：数据以 JSON 文件落盘，无需安装数据库。
- **开箱即用**：`node server.js` 即可启动。

## 二、功能特性

### 1. 用户与账户
- 注册：用户名须为 **4–16 位纯英文字母**，含密码、确认密码、年级、昵称。
- 登录 / 退出登录，Session 有效期 **30 分钟**。
- 连续 **5 次**密码错误锁定账号 **10 分钟**。
- 个人设置（`/settings`）：修改昵称、年级、密码等。

### 2. 错题管理（我的错题）
- 新增错题：标题、年级、学科、错误类型（计算失误 / 概念混淆 / 审题错误 / 记忆遗漏 / 其他）、题目内容、标准答案、解析、图片附件（每题最多 **5 张**，单张 ≤ 2MB，支持 JPG / PNG / GIF / WEBP）。
- 编辑 / 删除（删除时**级联清理磁盘图片**，无孤儿文件）。
- 公开 / 私有开关：私有错题仅本人可见，公开错题进入「错题广场」。
- 详情页「**显示 / 隐藏答案与解析**」：标准答案与解析整体联动切换，默认隐藏，且经 HTML 转义防 XSS。

### 3. 公共错题广场（首页）
- 浏览全站公开错题，支持：
  - 关键词搜索（题目 / 类型 / 年级 / 学科）
  - 年级、错误类型、学科三维筛选
  - 分页浏览、卡片缩略图
- 对公开错题可**点赞 / 收藏**（切换语义：再次点击即取消）。

### 4. 错题详情
- 完整展示题目、答案、解析、图片画廊。
- 作者可在详情页为错题**追加 / 删除图片**。
- 答案与解析一键显隐（联动）。
- 点赞 / 收藏 / 分享。

### 5. 错题分析（可视化报告）
- 原生 Canvas 绘制图表（零图表库）：
  - 按**错误类型**的甜甜圈饼图
  - 按**年级**、按**学科**的水平条形图
- 自动生成改进建议（依据各错误类型占比）。
- 概览统计：错题总数、涉及学科、各维度分布。

### 6. 错题排行榜
- 支持按**学科**查看榜单。
- 按点赞数 / 收藏数排序，展示热门公开错题。

### 7. 识别错题（OCR 智能识别）
- 浏览器端调用 **Tesseract.js**（CDN，免费、免密钥、无需后端）识别整卷图片文字。
- **图像增强（显著提升识别率）**：识别前自动对图片做**灰度 → Otsu 二值化 → 合理分辨率缩放**，并自动处理暗底照片（反相为黑字白底），大幅改善印刷体识别质量。
- **分页模式自适应**：可按试卷版式（单栏 / 双栏 / 自动）选择 Tesseract 的 `tessedit_pageseg_mode`；自动模式在首次识别题号过少时会切换分页策略重试，取更优结果。
- **题号容错解析**：支持 `1.` `1)` `1、` `1．` `第3题` `一、` `（1）` `（1）` 等多种题号格式；对 OCR 把 `1.` 误识别成 `l./I.`、把 `0.` 误识别成 `o./O.` 做自动纠正；正文内「第X题」可补全题号；自动过滤试卷前言 / 说明等噪声块。
- **规则解析批改标记**：
  - 打叉 ✗/×、标注「错 / 误」、出现「扣分 / 扣 N 分 / 减 N 分」→ 判为**错题**（已收紧：数学题里的 `x-2` 等不会被误判为扣分）
  - 打勾 ✓/√、标注「对 / 正确」→ 判为**正确**
  - 无标记 → **待确认**（需人工核对）
- **智能去重**：同题号（跨页 / 重复）自动合并，状态取最严重（错 > 部分 > 对）；「既打叉又扣分」只计 **1 次**错误。
- **人机协同**：提供「补充说明」框，可手填「第 3 题错、第 5 题扣 2 分」提升准确率；结果区可展开 OCR 原文核对。
- **离线降级**：OCR 引擎加载失败自动切换「手动添加」模式。
- 解析结果可勾选、批量 / 单条「加入错题集」（自动预填标题与解析）。

### 8. 定时复习（艾宾浩斯记忆曲线）
- 每道错题在**提交时刻**记一个基线时间，系统按艾宾浩斯遗忘曲线自动安排 **6 个复习阶段**：提交后的第 **1 / 2 / 4 / 7 / 15 / 30 天** 各复习一次。
- 「今日复习」页（`/review`）按当前日期算出**今天应当巩固的错题**并集中展示；逾期题目会排在前面并提示逾期天数。
- 每题展示**复习进度**（已复习阶段 / 6）、下次复习日期与解析要点；点击「✅ 我已复习」即记录本次复习，系统自动推进到下一阶段。
- 全部 6 个阶段完成后该题从复习列表移除，并显示「全部完成」。
- 复习计划为**个人维度**：仅本人可见自己的复习安排（私有 / 公开错题均计入本人复习）。

## 三、技术架构

```
server.js                入口：HTTP 服务、静态资源（含 SPA 入口）、路由分发、上传解析、启动钩子
frontend/                Vue 3 前端（Vite 工程，构建产物输出到 public/dist）
  index.html             SPA 入口 HTML（含 Tesseract.js CDN）
  vite.config.js         Vite 配置（dev 代理 /api、/img → 后端 :3000；构建输出 public/dist）
  src/
    main.js              SPA 启动入口
    App.vue              根组件（导航栏 + 路由出口 + 全局 Toast / Modal）
    router/index.js      路由表（history 模式，含登录守卫 beforeEach）
    store/               auth.js（登录态）、ui.js（Toast / Modal）响应式全局状态
    api/index.js         所有 /api 调用的封装
    components/          AppNav / ErrorCard / Pagination
    views/               11 个页面视图（Plaza / Detail / Add / MyError / Rank / Report / Review / Settings / Login / Register / AiFind）
    utils/               charts.js（Canvas 图表）/ aiFindParse.js（OCR 解析）/ format.js（枚举与格式化）
    styles/global.css    全局样式
tools/
  fileLock.js            文件锁，防并发写冲突
  crypto.js              MD5 加盐（盐值：错题系统2026）
  id.js                 自增 ID 生成
  fileOpt.js             JSON 文件读写（含数据模板）
  multipart.js           原生 multipart/form-data 解析（图片上传，零依赖）
middleware/
  auth.js                Session 鉴权（可选鉴权 + 强制鉴权）
  cors.js                跨域处理
  validator.js           参数校验（年级 / 学科 / 类型枚举、图片白名单）
service/
  userService.js         注册 / 登录 / 个人设置 / 锁定
  errorService.js        错题增删改查、列表、点赞、收藏、图片落库、分析报告
  imageService.js        图片落盘 / 校验 / 物理清理
route/
  userRoute.js            /api/user/*
  errorRoute.js           /api/error/*（含上传）
public/
  dist/                  ⭐ 前端构建产物（Vue SPA），由 server.js 以 SPA 模式托管（history 回退到 index.html）
  img/                   静态图片（默认头像 / 空态图 / 上传目录）
data/                     运行时数据（user / error / like / collect / session / autoId JSON）
logs/                     运行日志
```

**关键设计**
- 后端纯原生实现，运行时无任何第三方依赖；图片上传用自研 multipart 解析。前端仅在**构建期**依赖 vue / vite，构建产物为静态文件由后端托管。
- 前后端分离：前端为独立 `frontend/` 工程，后端保持不变的 REST API；`server.js` 同时托管 `/api`、`/img` 与构建后的 SPA。
- 文件锁串行化写操作，避免并发损坏 JSON。
- 所有用户输入前后端双重 `escapeHtml` 防 XSS。
- 静态目录做了**路径穿越防护**（无法读取 `data/`、`../` 等）。

## 五、快速开始

### 环境要求
- Node.js **≥ 14**（推荐 18+；开发验证使用 22.x）
- 前端开发 / 构建需安装依赖：`cd frontend && npm install`

### 启动（生产模式，推荐）
```bash
cd /Users/hanks/Desktop/wrongSet
node server.js
# 默认监听 http://localhost:3000
```
`server.js` 同时托管已构建的前端 SPA（`public/dist`）与后端 API，开箱即用。

### 前端开发模式（热更新）
```bash
cd frontend
npm install      # 首次需安装依赖
npm run dev      # Vite 开发服务器，默认 http://localhost:5173
```
开发服务器已将 `/api` 与 `/img` 代理到后端 `http://localhost:3000`，因此开发时后端需单独启动（`node server.js`）以提供 API 与图片。

### 重新构建前端（修改 frontend 后）
```bash
cd frontend
npm run build    # 产物输出到 public/dist，由后端直接托管
```

启动钩子会自动：生成数据模板（首次）、清理过期 Session、修复自增 ID。

### 访问
- 生产模式：浏览器打开 [http://localhost:3000](http://localhost:3000)
- 开发模式：浏览器打开 [http://localhost:5173](http://localhost:5173)

未登录用户可浏览广场与排行榜；新增 / 编辑 / 分析 / 识别错题等需先登录（受保护路由自动跳转登录）。

## 七、使用提示

1. **首次使用先注册**：用户名仅限纯英文字母（4–16 位）。
2. **收录错题**：在「新增错题」填写完整信息；如需配图，可先选图上传再提交（每题 ≤ 5 张）。
3. **共享与发现**：将错题设为「公开」后会出现在广场，可被他人点赞收藏；也可在广场发现他人的优质错题。
4. **识别整卷错题**：进入「识别错题」，上传整张试卷图片（可多页），系统 OCR 后自动解析批改标记；若手写符号识别不准，请在「补充说明」手动校正，并在结果区勾选核对，确认后一键加入错题集。
5. **查漏补缺**：「错题分析」按类型 / 年级 / 学科可视化分布并给出改进建议；「错题排行榜」可按学科看热门错题。
6. **定时复习**：提交错题后，系统会在第 1/2/4/7/15/30 天自动将其纳入「今日复习」，按节奏巩固记忆；逾期题目会优先排列并提示逾期天数。

## 八、已知局限

- **OCR 对手写批改符号（手画叉 / 勾）识别较弱**，主要靠「文字标记 + 扣分数字」判断，建议配合「补充说明」人工校正。
- **OCR 引擎从 CDN 加载，需联网**；离线时自动降级为「手动添加」。
- 登录错误密码当前返回 **400**（非标准 401），功能正确，后续可规范化。
- 数据以本地 JSON 文件存储，适合个人 / 单机使用，未做横向扩展与多用户并发优化。
